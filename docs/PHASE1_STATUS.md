# Phase 1 status

The initial pipeline has been tested end-to-end using **synthetic test data**.

This confirms that:
- data loading works;
- quality control works;
- a quiet-time baseline can be calculated;
- storm windows can be flagged;
- TEC anomalies can be calculated;
- figures and summary files are produced.

**No scientific conclusion has been drawn from the synthetic data.**

The next step is to replace the synthetic CSV with a real NASA/JPL GUARDIAN or IGS TEC dataset and repeat the analysis.
